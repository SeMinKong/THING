# Simulation

이 디렉터리는 `assets/`의 시뮬레이션 자산, `urdf/`의 로봇 모델과 `isaaclab/`의 학습·평가 실험을 관리합니다.

로봇손 관절 모델과 Isaac Lab 실험을 관리합니다.

- `assets/`: USD 등 시뮬레이션 자산
- `urdf/`: 로봇 기술 파일
- `isaaclab/`: 환경 설정과 학습 실험

Isaac Sim/Lab과 sim-to-real은 현재 3주 MVP의 제외 범위입니다. 실물 7축 제어,
안전 및 파지 인수 시험을 완료한 뒤 Post-MVP 작업으로 진행합니다.
