# 안전 상태 시험 절차

## 준비

- 로봇손을 고정하고 주변 작업자를 안전거리 밖으로 이동시킵니다.
- 비상정지와 모터 전원 차단이 물리적으로 동작하는지 먼저 확인합니다.
- 낮은 속도·전류 제한과 편 손 안전 자세를 사용합니다.

## 시험 항목

1. 정상 RUN 중 MIMIC 명령을 끊고 200–500ms 설정값에서 timeout을 확인합니다.
2. 짧은 단절에서 HOLD, 장시간 단절에서 SAFE로 전환되는지 확인합니다.
3. 네트워크 복구 후 명시적 재개 입력 없이 움직이지 않는지 확인합니다.
4. 한 모터의 통신을 끊고 해당 motor ID와 FAULT가 표시되는지 확인합니다.
5. 설정된 전류·온도 기준 초과를 모의하여 일반 명령이 차단되는지 확인합니다.
6. 비상정지로 모터 전원이 차단되고 해제 후 자동 재동작하지 않는지 확인합니다.

각 시험에 commit, 설정 파일, timestamp, 상태 토픽과 실제 관찰 결과를 기록합니다.
