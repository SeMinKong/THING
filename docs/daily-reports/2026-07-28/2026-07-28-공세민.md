## 오늘 한 일

- 손가락 구동용 spool을 제작하고 XL330 모터를 장착한 뒤, 각 손가락의 텐던을 연결함.
- 엄지·검지·중지·약지·소지 굽힘과 엄지 대립·벌림을 포함한 7축 구성을 정리함.
- 각 손가락이 텐던을 당겨 굽혀지는 방향을 기준으로 모터 ID와 구동 축 구성을 정리함.
- 기존 `calibration` 디렉터리를 정리하고, `~/thing_pjt/motor`에 새 모터 제어 환경을 구축함.
- Python 가상환경 `.venv`를 구성하고 `dynamixel-sdk`를 설치함.
- 7개 모터 스캔, 단일 모터 제어, 키보드 제어, 전체 원위치(2048) 복귀 스크립트를 작성함.
- 키보드 제어에 개별 정지(`Space`)와 전체 정지(`s`) 기능을 추가함.

## 결과 및 확인 자료

- 7개 모터 모두 통신이 정상임을 확인함.
- 각 모터에서 Model `1200`, Operating Mode `5`(전류 기반 위치 제어), Torque OFF 상태를 확인함.
- 모터 제어 기본값을 아래와 같이 설정함.

| 항목 | 설정값 |
| --- | --- |
| Profile Velocity | 300 |
| Profile Acceleration | 1500 |
| Current Limit | 1470 mA |
| Goal Current | 1470 mA |
| Goal PWM | 885 (100%) |

## 막힌 점 또는 위험 요소

- 텐던 장력, 스풀 권취 방향, 손가락별 가동 범위에 따라 같은 목표 위치라도 실제 굽힘량이 달라질 수 있어 축별 위치 보정이 필요함.
- 현재 Torque OFF 상태이므로, 구동 전에는 손가락의 초기 자세와 안전 가동 범위를 확인한 뒤 토크를 활성화해야 함.
- 스풀·텐던 구동부에 손이나 의복이 끼이지 않도록 저전류·저속 조건에서 단계적으로 동작을 검증해야 함.
