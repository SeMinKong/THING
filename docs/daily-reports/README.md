# 데일리 리포트

## MR 타이틀 컨벤션

```text
[Week NN] 이름 데일리 리포트
```

예시: `[Week 01] 공세민 데일리 리포트`

이 제목과 `docs/week-NN-영문이름` 브랜치는 일반 작업의 Jira 키 규칙에 대한 데일리 리포트 예외입니다.

이 디렉터리는 팀원별 당일 작업, 결과, 장애 요소와 다음 작업을 짧게 기록합니다.

날짜별로 `YYYY-MM-DD` 디렉터리를 만들고, 각 팀원은 해당 디렉터리에
`YYYY-MM-DD-이름.md` 형식의 파일을 하나씩 작성합니다. 보고서는 `TEMPLATE.md`를
복사해서 사용합니다.

보고서의 `관련 Jira 작업`에는 그날 수행한 Jira 키를 기록하고, 관련 작업이 없으면 `없음`으로 작성합니다.

```text
docs/daily-reports/
├── README.md
├── TEMPLATE.md
└── 2026-07-15/
    ├── 2026-07-15-공세민.md
    ├── 2026-07-15-팀원2.md
    └── ...
```

## 주차별 제출 흐름

1. 월요일에 최신 `develop`에서 `docs/week-NN-영문이름` 브랜치를 생성합니다.
2. `[Week NN] 이름 데일리 리포트` 제목으로 `develop` 대상 Draft MR을 만듭니다.
3. 매일 같은 브랜치에 날짜별 보고서를 commit하고 push합니다.
4. 금요일에 Draft를 해제하고 리뷰받은 뒤 한 번 병합합니다.

세부 규칙은 [협업 규칙의 일일 보고서 예외](../../CONTRIBUTING.md#8-일일-보고서-예외)를 참고합니다.
