# 시스템 아키텍처

## 데이터 흐름

```text
사용자 손
  → RGB 카메라
  → 손 landmark 검출
  → 손가락 굽힘/엄지 대립 값 계산
  → 필터 및 안전 제한
  → 시리얼 명령
  → 마이크로컨트롤러
  → 서보모터
  → tendon 및 로봇손 관절
```

## 구성 요소

- 기구: 손가락 링크, 관절, tendon guide, spool, 복귀 탄성체
- 전자: 서보모터, 마이크로컨트롤러, 서보 전원, 비상정지
- 펌웨어: 명령 수신, 각도 제한, 서보 출력, 통신 timeout
- 비전: landmark 검출, 캘리브레이션, 동작 매핑, 필터링
- 시뮬레이션: 관절 모델, 파지 과제, 물리 파라미터 실험
- 시험: 파지 성공률, 반복 내구성, 지연시간, 안전 동작
