# 프로젝트 상태

기준일: 2026-07-28

## 완료

- XL330-M288-T 7개 검색 성공
  - BUS_A: ID 1, 2, 3
  - BUS_B: ID 4, 5, 6
  - BUS_C: ID 7
- 무부하 소폭 회전 시험 통과
- 모터 전기적 중앙 위치 `2048` 이동 확인
- 실제 손용 Current-based Position 제어 코드 작성
- Dry Run, 안전 확인 문자열, 텔레메트리, 오류 감시, 접촉 정지 구현
- Ø2 mm 텐던용 Ø12 mm 2피스 스풀 설계
- 스풀 STL의 연결성·매니폴드·치수 검증

## 진행 중

- 2피스 스풀 3D 프린팅
- 스풀과 모터 호른의 실제 체결 공차 확인
- 텐던 연결 및 초기 장력 설정

## 아직 미완료

- ID 1~7과 실제 손가락/엄지 축의 물리 매핑 확정
- 축별 `open_raw`, `closed_raw` 보정
- 실제 손 포즈 시퀀스 실행
- 원통 파지와 엄지–검지 집기 반복 시험
- ROS 2, 비전, 웹 제어 연동

| ID | 임시 역할 |
|---:|---|
| 1 | 엄지 굽힘 |
| 2 | 검지 굽힘 |
| 3 | 중지 굽힘 |
| 4 | 약지 굽힘 |
| 5 | 소지 굽힘 |

| 7 | 엄지 벌림 |

## 다음 작업

1. 출력된 베이스와 드럼의 체결·편심·간섭 확인
2. 모터 ID와 실제 텐던 경로 표시
3. 텐던 연결
4. `confirm-map` 실행
5. ID 1부터 한 축씩 끝점 보정
6. 전체 포즈 Dry Run 검토
7. 실제 `open → fist → point → pinch → cylinder` 시퀀스 실행

텐던을 연결한 뒤에는 무부하용 과거 속도·전체 범위 스크립트를 사용하지 않는다.
