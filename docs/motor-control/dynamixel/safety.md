# 안전 지침

이 프로젝트는 텐던, 회전 스풀, 7개의 액추에이터를 사용한다. 소프트웨어의 Torque Off만을 비상 정지 수단으로 사용하지 않는다.

## 실동작 전

- 모터 전원을 즉시 끌 수 있는 물리 스위치 또는 전원 차단 수단을 손이 닿는 곳에 둔다.
- 손, 옷, 머리카락, 공구를 스풀과 텐던에서 치운다.
- 전원을 끈 상태에서 모터 ID, 텐던 경로, 감김 방향과 체결 상태를 확인한다.
- 스풀의 편심, 프레임 간섭, 나사 풀림, 텐던 마모를 확인한다.
- `scan → plan → mapping confirm → 단일 축 보정 → show Dry Run → 실제 동작` 순서를 지킨다.
- 첫 보정은 ID 1 하나부터 시작한다.

## 현재 초기 안전값

- 보정 Goal Current: 80 mA
- 기본 동작 Goal Current: 축에 따라 90~100 mA
- 하드웨어 Current Limit 상한: 150 mA
- 소프트웨어 온도 정지: 55 °C
- 기본 조그: 25 raw

이 값은 현재 시제품의 보수적인 시작값이다. 다른 손, 스풀, 텐던, 전원 구성에 검증 없이 복사하지 않는다. XL330의 Current Limit은 프로그램이 더 낮은 값으로 변경하면 전원 재인가 후에도 유지되는 EEPROM 값이다.

## 즉시 전원을 꺼야 하는 상태

- 텐던이 홈에서 벗어나거나 겹쳐 감김
- 비정상 소음, 진동, 냄새 또는 연기
- 스풀이나 프레임의 변형
- 손가락이 기구 한계를 넘어가려는 움직임
- 프로그램이 중지됐는데 토크가 남아 있음
- 직렬 통신 오류가 반복됨

## 금지

- 보정되지 않은 7축 전체 동작
- 텐던 연결 상태에서 과거 무부하용 전체 범위·속도·연속 회전 코드 사용
- 손가락이나 물체를 회전 스풀 가까이 둔 채 보정
- 전원이 켜진 상태에서 모터·통신·전원 케이블 연결 또는 분리
- `2048`을 실제 손의 공통 기본 자세로 간주

상세 조작 절차는 [hand-motion.md](hand-motion.md)를 따른다.
