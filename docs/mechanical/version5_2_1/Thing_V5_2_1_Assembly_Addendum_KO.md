# Thing V5.2.1 Closed-Guide 조립·설계 부록

## 1. 문서 범위와 상태

이 문서는 Thing V5.2.1에서 구현된 폐쇄형 힘줄 통로와 분리형 손가락 링크의 조립 방법을 정리한 한국어 부록이다. V5.2의 관절축, 가동 범위, 핀·M2·M3·CMC 인터페이스, 힘줄 작용선과 복귀 동역학은 유지하며, 기존의 측면 삽입 슬롯을 축방향으로 실을 넣는 폐쇄 통로로 변경한 상태를 다룬다.

아래 치수와 수량은 현재 모델의 설계값이다. 디지털 형상·관절 스윕·STL 검증은 통과했지만, 실물 출력성, 인장 강도, 반복 굴곡 수명에 대한 최종 검증 결과는 아직 확정하지 않았으며, 이 문서는 실물 성능 인증을 의미하지 않는다.

## 3. 폐쇄형 힘줄 통로 35개

총 35개 기능 통로는 일반 폐쇄 가이드 32개와 CMC-B 특수 통로 3개로 구성된다. 힘줄과 라이너는 가능한 열린 끝에서 통로 축을 따라 삽입해야 한다. 관절 간섭을 피해야 하는 `LITTLE_A5` 한 곳은 기존 C형 외피 전체를 메우는 대신, 내부 `Ø2.40 mm` 통로를 완전히 둘러싸는 짧은 폐쇄 포획 링을 사용한다.

| 구분 | 수량 | 소유 부품 | 현재 구현 단면과 유지 사항 |
|---|---:|---|---|
| 일반 폐쇄 가이드 | 32 | 각 해당 링크 | 일정 직경 통로 `Ø2.40 mm` 유지. 축방향 삽입 방식이며 기존 힘줄 중심선·작용선은 유지된다. |
| CMC-B `B_NEG` moving compound | 1 | `THUMB_METACARPAL` | 폐쇄 복합 스웨이지 형상. 상류 `Ø2.40 mm`, 벨마우스 `ID 2.60 → 1.30 mm`, `Ø1.30 mm` 목 구간, 하류 `Ø3.40 mm` 포켓과 스웨이지 스톱을 유지한다. 일반 관통 구멍으로 변경하면 안 된다. |
| CMC-B `B_POS` fixed stepped | 1 | `THUMB_YOKE` | 폐쇄 계단형 PTFE 페룰. 주 통로 `Ø2.40 mm`, 스톱 목 `Ø1.60 mm`, 외경 `5.20 mm`를 유지한다. |
| CMC-B `B_NEG` fixed stepped | 1 | `THUMB_YOKE` | 기존 측면 서비스 슬롯을 닫은 폐쇄 계단형 PTFE 페룰. 주 통로 `Ø2.40 mm`, 스톱 목 `Ø1.60 mm`, 외경 `5.70 mm`를 유지한다. |
| **합계** | **35** |  | **일반 32개 + 특수 3개** |

### 관절 여유를 위한 소형 폐쇄 가이드 두 곳

- `INDEX_A5`, `MIDDLE_A5`, `RING_A5`: 폐쇄부 외경 `Ø4.20 mm`, 내부 `Ø2.40 mm`, 명목 방사 벽 `0.90 mm`의 소형 전장 폐쇄 튜브이다.
- `LITTLE_A5`: 폐쇄부 외경 `Ø4.20 mm`, 내부 `Ø2.40 mm`, 길이 `1.60 mm`의 폐쇄 포획 링이다. 기존 통로 중심을 따라 관절 반대쪽으로 `1.40 mm` 이동해 배치했다. 링 바깥의 기존 C형 외피가 일부 보일 수 있지만, 힘줄은 이 완전 폐쇄 링을 관통하므로 측면으로 빠질 수 없다.
- `THUMB_MCP_BOWDEN_RETENTION`: 폐쇄부 외경 `Ø4.20 mm`, 내부 `Ø2.40 mm`이다. 기존 힘줄 축을 바꾸지 않고 그 축을 따라 중수골 방향으로 `2.00 mm` 이동하여 중수골에 직접 융합했다. 초기 보강 목은 CMC 요크 간섭 때문에 최종 모델에서 사용하지 않는다.

`B_NEG` moving compound의 설계 구간은 통로 축 좌표 기준으로 목이 `t=0.35–0.90 mm`, 하류 포켓 시작이 `t=0.80 mm`이다. `B_POS` fixed stepped는 주 통로 `-2.50–1.80 mm`, 스톱 목 `1.80–2.50 mm`이며, `B_NEG` fixed stepped는 주 통로 `-3.20–1.80 mm`, 스톱 목 `1.60–2.80 mm`이다. 이 겹침과 계단은 종단 및 PTFE 정지 기능을 위한 현재 설계이므로 임의로 드릴 관통하거나 단일 직경으로 보정하지 않는다.

## 4. 축방향 삽입과 관절 핀 조립 순서

폐쇄 통로는 조인트를 결합한 뒤 옆에서 힘줄을 넣을 수 없다. 따라서 다음 순서를 기본 조립 절차로 사용한다.

1. 오목 숫자와 부품 이름을 함께 확인하여 각 링크를 손가락 순서대로 배치한다.
2. 링크를 서로 분리한 상태에서 통로 입구의 버, 브리징 처짐, 서포트 잔여물과 막힘을 확인한다.
3. 필요한 일반 통로마다 짧은 `OD 2.0 mm` PTFE 라이너를 열린 끝에서 축방향으로 삽입한다.
4. 힘줄을 각 라이너와 폐쇄 가이드의 축을 따라 링크별로 순서대로 통과시킨다.
5. 힘줄 경로가 확보된 뒤에만 MCP·PIP·DIP 및 엄지 관절을 정렬하고 관절 핀을 삽입한다.
6. 핀 조립 후 낮은 장력으로 전 가동 범위를 천천히 움직여 힘줄 끼임, 라이너 돌출, 관절 틈을 가로지르는 튜브가 없는지 확인한다.

조립 편의를 위해 힘줄과 라이너를 먼저 끼운 링크들을 관절 순서대로 모아 둔 다음 핀을 체결한다. 통로 옆면을 절개하거나 힘줄을 측면에서 눌러 넣지 않는다.

### CMC-B 특수 통로 조립 주의

- `B_POS/B_NEG` fixed stepped: `OD 2.0 mm` PTFE 라이너를 `Ø2.40 mm` 주 통로에 축방향으로 넣고 `Ø1.60 mm` 스톱 목에서 멈춘다. 라이너가 목을 통과하도록 밀거나 목을 확공하지 않는다. 힘줄만 목을 지나도록 구성한다.
- `B_NEG` moving compound: V5.2에서 이어진 스웨이지 종단, `Ø1.30 mm` 목과 `Ø3.40 mm` 포켓을 보존한다. PTFE 라이너를 작은 목까지 강제로 관통시키지 않으며, 힘줄과 종단 부품은 축방향으로 조립한다.

## 5. 짧은 PTFE 라이너 사용 권장

현재 조립 정책은 링크 단위의 짧은 `OD 2.0 mm` PTFE 라이너 사용을 전제로 한다. 하나의 긴 튜브로 움직이는 관절을 가로지르기보다 링크마다 분리된 짧은 라이너를 사용해야 굴곡 시 튜브가 관절축을 밀거나 유효 모멘트 암을 바꾸는 위험을 줄일 수 있다.

라이너 길이는 현재 모델에서 단일 확정값으로 지정되지 않았다. 실물 링크에 맞춰 다음 조건으로 결정한다.

- 링크 내부 안내 구간은 덮되 관절 틈으로 돌출하지 않을 것
- 핀, 조인트 스톱, 계단형 페룰의 어깨와 간섭하지 않을 것
- 끝단을 직각으로 절단하고 찌그러짐·버를 제거할 것
- 조립 전 힘줄이 라이너 내부에서 손으로 부드럽게 왕복하는지 확인할 것

## 6. 내부 서포트와 슬라이싱 주의

폐쇄되고 기울어진 통로 안에 슬라이서가 생성한 서포트가 들어가면 제거가 어렵고 축방향 삽입이 불가능해질 수 있다. 출력 전 Bambu Studio의 레이어 미리보기에서 `Ø2.40 mm` 주 통로, `Ø1.60 mm` 스톱 목, `Ø1.30 mm` 스웨이지 목과 `Ø3.40 mm` 포켓 내부를 단면별로 확인한다.

- 힘줄 통로 내부에는 슬라이서 서포트가 생성되지 않도록 서포트 차단 영역과 출력 방향을 조정한다.
- 통로 천장의 처짐 또는 브리징 실패 가능성도 레이어 미리보기와 실물 쿠폰으로 확인한다.
- 출력 후 보이지 않는 잔여물을 드릴로 무리하게 밀어내지 않는다. 특히 세 특수 통로의 목과 포켓은 기능 형상이므로 확공 금지 대상이다.
- 모델 생성 과정에서 일반 가이드를 소유 부품에 연결하기 위해 추가된 구조 브리지는 출력물의 일부이다. 이것은 슬라이서가 만드는 제거용 내부 서포트와 다르므로 잘라내지 않는다.

## 7. 디지털 검증 결과와 실물 검증 계획

현재 배포 파일은 다음 디지털 검사를 통과했다.

- 구조 부품 17개와 보정 쿠폰 8개: 단일 메시 아일랜드, 비매니폴드 가장자리 0, 양의 체적.
- 폐쇄 통로 35개: 총 105개 방사 단면에서 내부 반경과 최소 벽 두께 검사 통과.
- 숫자 각인 15개: `0/1/2/3/4`가 각각 3개 링크에 적용되었고, 각인 후 잔여 벽 두께 조건 통과.
- 네 손가락: 4개 손가락 × 4개 자세에서 V5.2 기준에 없던 새 충돌 쌍 0.
- 엄지 굽힘: 4개 자세에서 새 충돌 쌍 0.
- 엄지 CMC: CMC-A와 CMC-B의 5도 간격 90개 조합에서 부품 충돌 0.
- STL: 개별 25개는 각각 수밀 단일 바디, 합본 1개는 25개 바디이며, 총 26개 모두 양의 체적과 일관된 와인딩 검사 통과.

아래 항목은 실제 재료와 출력 조건에서 수행해야 할 물리 검증 계획이다.

아래 항목은 양산 또는 실제 구동 전에 수행해야 할 물리 검증 계획이다. 현재 문서에는 합격 결과를 기록하지 않는다.

| 검증 항목 | 계획된 확인 내용 | 현재 상태 |
|---|---|---|
| 통로 쿠폰 | 상속된 `ID 2.40 mm` 보어 래더 쿠폰을 실제 재료·노즐·레이어 조건으로 출력하고, `OD 2.0 mm` PTFE가 서포트 잔여물 없이 축방향으로 들어가는지 확인 | 미실시 또는 결과 미확정 |

시험 하중과 반복 횟수는 현재 검증 계획값이며 확정 성능 수치가 아니다. 재료, 출력 방향, 레이어 접합, 실제 힘줄 및 종단 부품이 정해진 뒤 결과를 기록하고 필요하면 기준을 개정해야 한다.

## 8. 조립·수정 금지 사항 요약

- 폐쇄 통로에 새 측면 슬롯을 만들지 않는다.
- 일반 통로 `Ø2.40 mm`와 세 특수 통로의 계단·복합 단면을 서로 혼동하지 않는다.
- `B_POS/B_NEG` fixed stepped의 `Ø1.60 mm` 스톱과 `B_NEG` moving compound의 `Ø1.30 mm` 목·`Ø3.40 mm` 포켓을 관통 확공하지 않는다.
- PTFE 라이너가 움직이는 관절 틈을 가로지르지 않게 한다.
- 핀을 먼저 조립한 상태에서 힘줄 또는 라이너를 측면 압입하지 않는다.
- 숫자 표기만으로 링크 구간을 판단하지 않고 반드시 부품 이름을 함께 확인한다.

이 부록은 V5.2.1의 현재 구현과 권장 조립 절차를 설명한다. 실제 출력 조건에서 쿠폰, 인장 및 반복 굴곡 검증을 완료하기 전에는 최종 강도나 수명을 보증하지 않는다.
