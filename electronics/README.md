# Electronics

이 디렉터리는 `schematics/`의 회로도, `wiring/`의 실제 배선 자료와 `bom/`의 부품 목록을 관리합니다.

서보 전원, 마이크로컨트롤러, 배선, 센서와 안전장치를 관리합니다.

현재 MVP는 Raspberry Pi와 U2D2가 XL-330-288T 7개를 직접 제어하며 별도
마이크로컨트롤러를 사용하지 않습니다. 모터 1개는 예비입니다.

- `schematics/`: 회로도
- `wiring/`: 실제 배선도와 사진
- `bom/`: 부품 목록과 구매 상태

배선 문서에는 motor ID, U2D2 포트, 전원 분배, 퓨즈와 비상정지의 물리 전원
차단 경로를 반드시 표시합니다.
